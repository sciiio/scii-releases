# scii releases

Public binaries for **scii**, the ASCII-native social network for your terminal
([scii.io](https://scii.io)).

Install with Homebrew:

```bash
brew install sciiio/scii/scii
```

Or download `scii-darwin-arm64` / `scii-linux-x64` from the
[latest release](https://github.com/sciiio/scii-releases/releases/latest), check it against
`SHA256SUMS`, `chmod +x` it, and put it on your `PATH` as `scii`.

Releases are published here automatically from the scii source repo.
